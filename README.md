# ArtifactConservationHK

> 香港文物保護資訊平台 · Hong Kong Artifact Conservation Information Hub

A one-stop web platform for Hong Kong citizens to find materials conservation information and promote this profession to the public.

## 🌐 Website

This site is deployed via **GitHub Pages** at:
`https://[your-github-username].github.io/Artifactconservationhk/`

## 📁 Project Structure

```
Artifactconservationhk/
├── index.html          # Main HTML file (bilingual ZH/EN)
├── styles.css          # Stylesheet (responsive design)
├── script.js           # JavaScript (language toggle, animations, form)
├── favicon.svg         # Site icon
└── README.md           # This file
```

## ✨ Features

- **Bilingual** — Traditional Chinese (繁體中文) / English toggle
- **Responsive Design** — Works on desktop, tablet, and mobile
- **Six Conservation Areas** — Paper, Ceramics, Wood, Stone, Textiles, Scientific Analysis
- **Resource Links** — ICOM-CC, LCSD, HKMoA, Getty Institute
- **Contact Form** — Inquiry form for conservation requests
- **Smooth Animations** — Scroll-triggered fade-in effects

## 🚀 Deploy to GitHub Pages

1. Create a repository named `Artifactconservationhk` on GitHub
2. Upload all files from this folder
3. Go to **Settings → Pages**
4. Set source to `main` branch, root folder `/`
5. Save — your site will be live in ~1 minute

## 🛠️ Customization

- Edit `index.html` to update content
- Modify `styles.css` `:root` variables to change colors
- Add pages by creating new `.html` files
